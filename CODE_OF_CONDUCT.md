# Code of Conduct

Be kind, be direct, assume good faith. This is a small project run by volunteers.

- Critique code and ideas, not people.
- No harassment, discrimination, or personal attacks — in issues, PRs, or anywhere the project is discussed.
- Respect that maintainers' time is limited; a closed issue is not an insult.

Problems? Email ishangupta3121@gmail.com. Reports are handled privately; behaviour that breaks this
will get a warning, then a block.

This is a condensed version of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
